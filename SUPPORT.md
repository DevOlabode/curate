# Support

GitHub Issues are for **bugs** and **planned work**. They are not a help desk.

## Using Curate

Install the extension from the store:

- [Chrome Web Store](https://chromewebstore.google.com/detail/curate/nlkfmdiphacjgicdcagonbfnpcdjfapo)
- [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/curate/ailonhflbailiggfiimmkkmbeoggbjpk)

Sign in inside the popup. There is no account signup on the marketing site. Privacy details are in [PRIVACY.md](PRIVACY.md).

## Running it yourself

Local API, unpacked extension, and landing preview are documented in [docs/development.md](docs/development.md).

## Bugs

If something is broken, [open a bug report](https://github.com/DevOlabode/curate/issues/new?template=bug_report.yml). Include steps to reproduce and your browser.

## Ideas

[Open a feature request](https://github.com/DevOlabode/curate/issues/new?template=feature_request.yml) before writing a large PR.

## Security

Report vulnerabilities privately. See [SECURITY.md](SECURITY.md). Do not file a public issue.

## Contributing code

See [CONTRIBUTING.md](CONTRIBUTING.md).

## What not to file as an issue

- "How do I install this?" — use the store links above
- "Can someone help me set this up?" — follow [docs/development.md](docs/development.md)
- Password reset or account access for the hosted API — use the in-extension flow, not GitHub
